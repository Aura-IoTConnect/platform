Built for real fleets, not a demo

Config-driven, not hard-coded

A DeviceType carries its own metric taxonomy — key, unit, safe range. Add an industry by adding seed data, not by shipping new code.

Real-time rules & alerts

Threshold rules evaluate on every reading. A breach opens an alert and can dispatch an actuator command automatically — the same control loop, whatever the metric.

AI agents with a feedback loop

Critical alerts get an automatic root-cause explanation. Every agent run can be scored, so quality is tracked over time instead of trusted blindly.

Gateways, tags & sites

Model a real hub-and-sensor topology, group devices with free-form tags, and organize a fleet into a site hierarchy — or bulk-onboard a whole batch from a CSV.

A real liveness signal

A heartbeat distinct from telemetry means you know a device is actually reachable, not just that its status field hasn't been touched.

MQTT or HTTP, your choice

Per-device credentials over either transport, with self-service provisioning so a device can create its own record instead of waiting on an operator.
